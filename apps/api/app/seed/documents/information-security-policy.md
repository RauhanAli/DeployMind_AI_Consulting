# Information Security Policy

All staff must use multi-factor authentication for email, the CRM and the document repository.
Client confidential information must only be stored in approved systems hosted in the United Kingdom.
Personal devices must never be used to store client data.

## Access control

Access to client files is granted on a need-to-know basis and reviewed every quarter by team leads.
Leavers have all system access revoked on their final working day.

## Incident reporting

Suspected security incidents must be reported to the IT Service Desk within one hour of discovery.
The Data Protection Officer decides whether a personal data breach must be reported to the ICO within 72 hours.

## Use of AI tools

Staff must not paste client confidential information into public AI tools.
Only AI assistants approved by the IT Security team may be used with client data.
